# ✅ Todo App

A full-stack Todo application with authentication and task management.

---

## 🚀 Features

- Add, edit, delete todos
- Mark todos as completed
- View all / completed / pending todos
- User signup & login
- Secure logout

---

## 🌐 Live Demo

👉 https://naviotech-project-todo-1.onrender.com

---

## 🧠 Tech Stack

**Frontend:** React (Vite), Tailwind CSS, React Router, Lucide Icons  
**Backend:** Node.js, Express.js, MongoDB, JWT

---

## ⚙️ Installation

```bash
git clone https://github.com/your-username/todo-app.git
cd todo-app
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
